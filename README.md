# 🤖 AI Resume Reviewer

> An AI-powered resume analysis web application that helps users review their resumes and receive intelligent feedback using Puter.js AI.

[Live Demo](https://ai-resume-reviewer-inky.vercel.app/) · [GitHub Repository](https://github.com/Piyush-D-E-V/Ai-Resume-Reviewer)

---

## 📌 Overview

**AI Resume Reviewer** is a React-based web application that uses **Puter.js AI** to analyze resumes and provide useful feedback.

The application is designed to help job seekers identify areas for improvement in their resumes and better understand how their resume can be strengthened.

---

## ✨ Features

* 📄 **Resume Review** — Analyze resume content using AI
* 🤖 **AI-Powered Feedback** — Get intelligent feedback from Puter.js AI
* 📊 **Resume Analysis** — Review different aspects of the resume
* 💡 **Improvement Suggestions** — Identify areas that can be improved
* 🎯 **Actionable Feedback** — Receive practical suggestions for improving resume content
* ⚡ **Interactive UI** — Simple and responsive resume-review experience
* 📱 **Responsive Design** — Works across desktop and mobile devices

## 🚀 Getting Started

### Prerequisites

Make sure you have installed:

* Node.js
* npm / pnpm / yarn

### Installation

Clone the repository:

```bash
git clone https://github.com/your-username/ai-resume-reviewer.git

cd ai-resume-reviewer
```

Install dependencies:

```bash
npm install
```

or:

```bash
pnpm install
```

### Run Locally

```bash
npm run dev
```

Open the application in your browser:

```text
http://localhost:5173
```
